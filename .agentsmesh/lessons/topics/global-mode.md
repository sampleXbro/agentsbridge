# Lessons: global mode

## Rules (apply unconditionally)

1. When implementing global mode for any target, add a `global` layout AND `rewriteGeneratedPath` that translates project-level paths (e.g. `.github/`) to global paths (e.g. `.copilot/`). Layout path resolvers alone are not enough — the engine uses `rewriteGeneratedPath` to transform generator output paths before writing. Verify a representative file lands at the correct global location. (L69)
2. Follow the full global-mode pattern in one pass: (a) global path constants, (b) `global` layout with `rewriteGeneratedPath`, (c) `mirrorGlobalPath` for cross-agent skill mirroring, (d) `globalCapabilities`, (e) `globalDetectionPaths`, (f) help text + docs. Model from Copilot/Cursor/Roo Code. Update all six together. (L174)
3. After editing a target's `rewriteGeneratedPath`/global layout, re-audit imports — every referenced constant (e.g. `CURSOR_COMPAT_AGENTS`) must be in the file's import list. Run `pnpm typecheck` and the target's `generate --global` CLI test; treat missing-symbol imports as a release gate. (L169)
4. When implementing global mode, import every required type (`TargetCapabilities`, `TargetLayout`) from `target.interface.js` and run `pnpm typecheck` immediately after adding the global layout. Do not assume copy-pasted patterns carried all imports. (L172)
5. Namespace global paths under shared parent directories so multiple targets do not collide. If multiple targets share `.gemini/`, `.agents/`, etc., each non-native one MUST use a namespaced subdirectory (e.g. Antigravity → `.gemini/antigravity/`, Gemini CLI native → `.gemini/`). The collision detector only special-cases `AGENTS.md`; other shared-path collisions throw. (L176)
6. In `import` flows, when `scope === 'global'`, only read tool-native subtrees under the home root (e.g. `~/.codex`, `~/.agents/skills`). Never run whole-tree `readDirRecursive` / `importFileDirectory` from `homedir()` — that blows the stack on symlink cycles (e.g. `~/.cache`) and scans the entire home tree. Add a `scope === 'global'` guard. (L170)
7. In any helper that fakes the home directory via env (`HOME`) for `--global` e2e, on `process.platform === 'win32'` ALSO set `USERPROFILE` (and defensively `HOMEDRIVE`/`HOMEPATH`) from the same path, because `os.homedir()` on Windows reads `USERPROFILE`, not `HOME`. Put this in the spawn helper, not at call sites. (L5)
8. For temp-dir symlink helpers that stage a fake home (e.g. `createTempProjectRoot(homedir())`), only symlink dot-entries (`.claude/`, `.cursor/`, …) and root-level files. Never symlink non-dot directories like `Desktop`/`Documents` — listings/walks over the project root (`listScopedAgentsFiles`, the 18-target normalizer) will traverse them and hang. (L228)
9. For `mirrorGlobalPath` skip/dual-mirror tests, derive eligibility from the run's actively-generated targets, not the configured set. `feature-loop.ts` passes the post-filter `targets` array to `mirrorGlobalPath`; using `targetFilter: ['copilot']` removes codex-cli from "active" even when it is in `config.targets`. To exercise the codex-cli skip, list both targets in `config.targets` and DO NOT pass `targetFilter`. (L186)
10. For global-mode structure-validation tests, call `generate()` from `src/core/generate/engine.ts` with `scope: 'global'` — not `runGenerate()` from the CLI commands, which returns an exit code (`Promise<number>`) instead of the generated files. Provide a `makeConfig()` helper returning a `ValidatedConfig` with target + features configured. (L180)
11. Derive global-mode e2e expectations from each target's descriptor/layout constants (e.g. Windsurf `workflows`, Roo `.roo-code`, Codex `config.toml`), not from historical path helpers. Whenever a path-rewrite helper is retired or global behavior shifts, update e2e assertions from descriptor constants and rerun the e2e Vitest config after `pnpm build`. (L67)
12. Keep canonical loader helpers (e.g. `loadCanonicalFiles()`) backward-compatible with BOTH project-root and canonical-dir inputs when adding scope awareness. Sweep every caller before tightening the signature — extend, install, and the loader test suite all pass project roots and expect the helper to locate `.agentsmesh/` itself. (L72)
13. When bridging generated global files into an importer fallback path in tests, copy the EXACT generated tree the round-trip needs — including `references/`, `scripts/`, `templates/`, and `assets/` — not just `SKILL.md`. (L59)
14. For `findGeneratedFile` in global structure tests, pass a plain string for exact path matching or an object with `stringContaining`/`stringMatching`. Never invent `{ exactPath: '...' }` — check the actual signature first. (L181)
