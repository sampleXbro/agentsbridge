## Findings (Ordered by Severity)

**No new findings in the lessons feature itself.** All three findings from `qa-report-2026-06-06.md` are confirmed fixed:

### 1. [was MEDIUM — FIXED] `import-md` raw `ENOENT` when no legacy `index.yaml`
- **Verification:** I2 (`--force`, no legacy), I3 (empty dir), I3v (`--verbose`), I6 (re-run after migration) all now return `No legacy lessons store found (.agentsmesh/lessons/index.yaml) — nothing to migrate.` (exit 1), with **no Node `fs` error and no stack trace** even under `--verbose`.
- **Fix location:** `src/cli/commands/lessons-write-handlers.ts` (existsSync guard on `lessonsPaths(root).index` before the unconditional read); stale docstring on `importLegacyLessons` corrected (`src/lessons/import-legacy.ts`).

### 2. [was LOW — FIXED] `query --format` silently accepted invalid values
- **Verification:** F2a (`xml`) and F2b (`jso`) now both reject with `Invalid --format: expected plain|md|json.` (exit 2), matching the `--top`/`--max-tokens` validators. Valid `plain|md|json` still pass.
- **Fix location:** `validateFormatFlag` in `src/cli/commands/lessons-handlers.ts:42`, called from `doQuery`.

### 3. [was LOW — FIXED] Global flags before the command name misparsed
- **Verification:** F3a (`--json lessons topics`), F3b (`--verbose lessons topics`), F3c (`--help lessons`) all resolve the command correctly now. F3d/F3e confirm `--version` is **deliberately excluded** from the valueless set so `plugin add --version <ref>` and bare `--version` both still work.
- **Fix location:** `VALUELESS_FLAGS = {json, verbose, help}` in `src/cli/index.ts`.

### Process observation (out of lessons scope, worth flagging)
- The `precommit` hook (`typecheck && lint:dead && test:coverage && lint-staged`) runs the full test suite, which **deletes untracked files under the working tree** (both untracked `tasks/reports/qa/qa-report-2026-06-06*.md` files were removed during a commit; the committed `2026-05-17` report survived). Reports must be `git add`-staged before committing, or committed `--no-verify`. Recommend investigating which test mutates the real working tree and scoping it to a temp dir.
