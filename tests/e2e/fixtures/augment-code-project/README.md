# AugmentCode Project Fixture

This directory contains a realistic AugmentCode project fixture for e2e testing.

It demonstrates:
- Rules in `.augment/rules/` with `always_apply` and `agent_requested` frontmatter
- Slash commands in `.augment/commands/`
- Native skills in `.augment/skills/` (agentskills.io spec)
- MCP servers and hooks in `.augment/settings.json`
- Workspace ignore patterns in `.augmentignore`
