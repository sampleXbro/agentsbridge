# Orders API

Realistic Codebuff (Freebuff) project fixture for agentsmesh e2e tests.

Codebuff configuration in this repo:

| Path                    | Purpose                                        |
| ----------------------- | ---------------------------------------------- |
| `AGENTS.md`             | Root knowledge file                            |
| `src/AGENTS.md`         | Nested knowledge file for the `src` directory  |
| `.agents/skills/`       | Skills, including one projected command        |
| `.agents/mcp.json`      | MCP servers                                    |
| `.agents/*.ts`          | User-authored agent modules (never generated)  |
| `.codebuffignore`       | Files Codebuff should not read                 |
