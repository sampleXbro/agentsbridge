# Trae Project Fixture

A realistic Trae IDE project fixture for AgentsMesh testing.

This project uses the Trae IDE configuration at `.trae/`:
- `.trae/rules/project_rules.md` — main project instructions
- `.trae/rules/*.md` — scoped rules (TypeScript, security)
- `.trae/skills/` — reusable AI skills
- `.trae/mcp.json` — MCP server configuration
- `.trae/.ignore` — AI indexing exclusions
